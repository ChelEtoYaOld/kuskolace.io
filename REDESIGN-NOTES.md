# Kus Koláče — редизайн

Обновлены первый экран, шрифты Fraunces + Manrope (включая чешские символы), сливочно-ягодная палитра, карточки, отступы и мобильная компоновка. Добавлены анимации появления, наведения и декоративного штампа; предусмотрен prefers-reduced-motion. CMS, API, категории и данные сохранены. Изменения стилей ограничены публичной частью сайта.

## Просмотр
Откройте DESIGN-PREVIEW.html в браузере. Это отдельная демонстрация дизайна с исходными данными из seed, не подключенная к рабочей базе. Поддерживает фильтры, просмотр состава и переходы по секциям. Изображения и Google Fonts загружаются через интернет. Полный сайт использует прежнюю инфраструктуру и команды из README.md.

## Проверки
- Успешная проверка синтаксиса восьми изменённых TS/TSX файлов через esbuild.
- CSS разобран PostCSS, Tailwind 4.1.13 успешно скомпилирован.
- Проверен серверный рендер Hero, Story и PastryShowcase с адаптерами для изображения и диалога; проверены сохранение всех товаров и фильтрация категории.
- Контраст: основной текст 13.94:1; вторичный текст 5.83:1; основная кнопка 7.85:1; светлый текст на зелёном 9.27:1.
- Браузерная визуальная проверка, загрузка внешних фото/шрифтов, полный Next.js build и работа с живой БД НЕ проверены: среда не предоставляет поддерживаемое управление браузером и рабочую конфигурацию сервера.
- Сайт не опубликован. Для запуска требуется существующая среда AutoCoder с её настройками БД/API.
